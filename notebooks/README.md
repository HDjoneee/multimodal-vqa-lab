# Notebook 索引

命名规则：`v<阶段>-<训练 QA 数>-<对照组数>-<实验类型>.ipynb`。按训练集规模从小到大排列。

| 文件 | 组数 | 训练 | 评估集 | 关键结果（Exact Match） |
| --- | ---: | --- | --- | --- |
| `v1-3200-4-pilot.ipynb` | 4 | 3,200 QA / 3,087 图 | test 320（35 类） | 仅文本 29.1%，图文融合 43.4%，微调 43.4% |
| `v2-12400-2-main.ipynb` | 2 | 12,400 QA / 2,000 图 | dev 4,960 词表内 | 仅文本 34.0%，图文融合 39.1% |
| `v2-12400-3-aligned.ipynb` | 3 | 12,400 QA / 2,000 图 | dev 4,960 词表内 | 34.5 / 38.8 / 37.9 |
| `v3-20989-2-main.ipynb` | 2 | 20,989 QA / 2,000 图 | dev 8,083 词表内 | 仅文本 36.8%，图文融合 42.6% |
| `v3-20989-3-aligned.ipynb` | 3 | 20,989 QA / 2,000 图 | dev 8,083 词表内 | 35.9 / 41.6 / 40.8 |

## 三种实验类型的含义

**`pilot`** — 四题型小规模验证。四类问题各抽 800 题，答案词表按类型分别建（2 / 11 / 12 / 10 类），总共 35 类。四组是仅文本、图文融合（冻结）、冻结续训 2 轮、解冻末层续训 2 轮；后两组从同一模型出发，用于分离"多训两轮"与"解冻骨干"两种影响。题型被人工均衡，不能当作完整 VQA v2 的成绩。

**`main`** — 主交付模型，对应 `scripts/top1000_experiment_source.py`。16 轮、batch 256，只训文本与冻结融合两组，追求最高分。三组里最好的那个数出自这里。

**`aligned`** — 受控对照，对应 `scripts/three_way_experiment_source.py`。10 轮、batch 32，三组超参完全一致，用来判断解冻末层是否有效。因为轮次预算低，绝对分数比 `main` 低约 1 个点。

## 同一规模为什么有两份

`-2-main` 与 `-3-aligned` 的训练数据完全相同，差别在训练预算和实验目的。同一个冻结融合模型在 `v3-20989-2-main` 里是 42.6%，在 `v3-20989-3-aligned` 里是 41.6%。数量题的图像增益在两份里也不一致（0 对 +4.7）。引用时必须标明出自哪一份。

## 三个阶段的差别

**v1** 是 35 类四题型，词表按题型分别构建，评估只有 320 题。规模小，但微调与冻结的差异最明显。

**v2** 换成 Top-1,000 闭集分类，词表来自官方全量训练集的答案频次。抽样受"每图恰好 6 或 7 题"配额限制，2,000 张图固定产出 12,400 条 QA。副作用是词表里 171 个类从未出现，开发集有 81 道题的答案类别训练时没见过。

**v3** 去掉 6/7 题限制，改成在所有 ≥6 题的图上按密度分层等比例抽样。训练集涨到 20,989 条，词表死类降到 100，开发集未见类题降到 60 道。评估集同时扩到 8,083 条。

## 呈现方式不同

`v1-3200-4-pilot` 与 `v2-12400-2-main` 是实际执行过的 notebook，每个代码单元下挂的是当时的 stdout。其余三份是先用 `scripts/build_notebook.py` 生成结构、再把 `results/` 里的曲线内嵌、最后把完整运行日志作为末尾单元附上。这样改评分口径后不必为了美观重跑训练。

重新生成带图与日志的 notebook：

```powershell
python scripts/build_notebook.py --source scripts/three_way_experiment_source.py --output notebooks/v3-20989-3-aligned.ipynb --attach-log results/three_way_run.log
```

## 一个不要混用的地方

v1 的 43.4% 与 v3 的 41.6% 不能直接比较。前者是 320 题测试集上的 35 类分类，后者是 8,083 题上的 1,000 类分类，难度、题型分布、随机波动全部不同。跨版本只能比同一指标的方向，不能比绝对数值。
